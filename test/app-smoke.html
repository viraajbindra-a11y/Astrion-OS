Astrion App Smoke Test

Iterates every processManager.register()-installed app, instantiates each in a hidden off-screen container, waits 250 ms for first paint, then checks: (1) launch threw no exception, (2) the contentEl has at least one child node, (3) no console errors fired during that window. Reports per-app pass / fail / empty / error so a UI breakage can no longer land silently. Sanity-check #5 (2026-05-02 audit) flagged this gap; this is the runner that closes it.

What does each tag mean?
pass — launch returned, content rendered, no errors during the 250ms window.
fail — launch threw an exception OR a console error fired inside the window.
empty — launch ran without throwing, but contentEl had no children after 250ms. Either the app is lazy-loading and didn't paint within the window (lazy stubs intentionally show "Loading…" first) or its render path is broken.
pending — currently being tested.
